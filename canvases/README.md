# Canvas 图解

Cursor Canvas 交互面板源码，与 `docs/how-it-works-visual-guide.md` 配套使用。

| 文件 | 用途 |
|------|------|
| `harness-mem-how-it-works.canvas.tsx` | 入门：项目怎么跑、7 张流程图、名词白话表 |
| `harness-mem-completion.canvas.tsx` | 完成度：五维评估、v5.0 证据链、能力矩阵 |

## 怎么打开

在 Cursor 中直接打开本目录下的 `.canvas.tsx` 文件，可渲染为侧边交互面板。

若 Cursor 工作区根目录就是 `harness-mem/`，从文件树点开即可；若侧边未自动弹出，双击文件也会渲染。
