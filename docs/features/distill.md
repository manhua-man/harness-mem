# Distill · 整理已结束的会话

用户在对话中告诉 Agent 要整理哪场讨论。Agent 根据项目、宿主和内容找到来源；有歧义时用会话主题请用户区分。选定后，运行时冻结原文版本与批次，下一次接续仍处理同一份内容。

Agent 读完每段原文才保存该段的阅读进度。中断后，新进程能从已保存的位置继续。Agent 判断哪些说法值得长期保留，区分用户决定、助手报告和执行证据，并与当前知识比较。运行时检查证据与来源版本、校验写入、生成 Note。用户只需看新增、补充、替换、确认的内容和仍未完成的事项。

已冻结的用户原话与独立文件证据按各自版本核验，来源聊天继续运行不会阻止保存；原生工具记录不可读取时会说明缺口，不能据此证明实际执行过某项操作。纠正旧的普通知识时，经过精确引文核验的新用户决定可以作为新依据，仍须逐点审阅完整旧正文、保留适用含义并核对旧条目版本；这不把旧证据重新认证为有效。确认旧知识或修订来源报告仍须核对原有证据。

日常整理保留原文。用户明确要求清理已整理原文时，先核对冻结批次的清理预览，实际删除以该次授权和来源复验为准。Agent 的读写与接续方法见 [Distill Skill](../../.agents/skills/distill/SKILL.md)。

Windows 上并发发布手工批次时曾出现读取批次 JSON 的 `PermissionError`，单独复跑该竞争用例通过。本次独立进程接续验证覆盖顺序暂停和恢复。
